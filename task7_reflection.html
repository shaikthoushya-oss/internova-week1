Reflection & Learning

In Week 1, I learned that HTML is the foundation of every website. It gives structure to a web page using elements like headings, paragraphs, links, images, lists, tables and forms. I also learned how the basic document structure works with the doctype, head and body, and why meta tags matter for character encoding and mobile screens.

The most challenging topic for me was forms, because there are many input types and attributes, and it took practice to use labels, radio buttons and dropdowns correctly. Tables were also tricky at first because rows and columns must be arranged carefully.

I enjoyed semantic HTML the most. Tags like header, nav, main, section, article and footer make code easier to read and also help search engines and screen readers understand the page. I also enjoyed building the mini project, since it let me combine everything I learned.

HTML will help me in web development because it is the base for CSS and JavaScript. Once I understand structure well, I can style pages and add interactivity with confidence.
